# Branded Purifier Website

This is the codebase for the Branded Purifier website, built with React, Vite, and TanStack Router.

## Technologies Used

- **Framework:** React
- **Routing:** TanStack Router & TanStack Start
- **Styling:** Tailwind CSS
- **Build Tool:** Vite
- **Language:** TypeScript

## Getting Started

### Prerequisites

You need Node.js and npm (or bun/yarn/pnpm) installed on your machine.

### Installation

Clone the repository and install dependencies:

```bash
npm install
# or
bun install
```

### Development Server

Start the development server:

```bash
npm run dev
# or
bun run dev
```

The application will be running at `http://localhost:5173`.

### Production Build

To create a production build:

```bash
npm run build
# or
bun run build
```
